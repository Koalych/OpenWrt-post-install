# OpenWrt Post-Install

Интерактивный мастер первоначальной настройки OpenWrt. Скрипты рассчитаны прежде всего на GL-MT3000 и OpenWrt 25.12 или новее, где используется пакетный менеджер `apk`.

## Запуск

Подключитесь к роутеру по SSH как `root` из интерактивного терминала и выполните:

```sh
wget -O /tmp/run.sh https://raw.githubusercontent.com/Koalych/OpenWrt-post-install/main/run.sh
sh /tmp/run.sh
```

`run.sh` загружает архив проекта во временный каталог, запускает `install.sh` с терминальным вводом и возвращает код завершения установщика. Перед запуском просмотрите скрипты и убедитесь, что понимаете изменения, которые они применяют.

При запуске открывается меню с разделами «Система», «Сеть», «Программы», «Дополнительные настройки» и «Полная настройка». Пункты изменения оболочки и отдельной настройки SSH пока отображаются как будущие функции.

## Требования

- OpenWrt 25.12+ с доступной командой `/usr/bin/apk`.
- Учетная запись `root` и интерактивная SSH-сессия с доступом к `/dev/tty`.
- Подключение к интернету для обновления пакетов и загрузки сторонних установщиков.
- Достаточно свободного места в `/overlay` для выбранных пакетов.
- На других моделях, кроме GL-MT3000, могут отличаться радиомодули, имена UCI-секций и доступность пакетов.

Основной шаг устанавливает `curl`, `openssh-sftp-server` и `luci-base`. Для выбранных функций дополнительно используются `apk`, `uci`, `wget`, `awk`, `sed`, `grep`, `ip`, `service` и утилиты OpenWrt.

## Что делает мастер

1. Проверяет наличие `apk` и просит подтвердить запуск на целевом устройстве.
2. Позволяет изменить LAN IPv4-адрес. При изменении сетевой настройки SSH-соединение прервётся; подключитесь заново по новому адресу и запустите мастер повторно.
3. Настраивает язык и тему LuCI, имя роутера, часовой пояс и, по желанию, пароль `root`.
4. Настраивает SSID и защиту Wi-Fi на штатных радиомодулях, включая вариант замены `wpad-basic-mbedtls` на `wpad-mbedtls`.
5. Предлагает базовые, персональные и произвольные пакеты; поддержку USB-накопителей и Transmission.
6. По выбору устанавливает AdGuard Home: переносит `dnsmasq` на порт 54, оставляет DNS клиентов на порту 53 и просит пройти мастер AdGuard Home в браузере. Затем настраивает upstream DNS, bootstrap DNS и локальные PTR-запросы.
7. По выбору устанавливает Tailscale, создаёт firewall-зону и маршруты LAN/WAN, включает объявление LAN-маршрута и exit node. Для завершения потребуется авторизация в Tailscale и подтверждение маршрутов в его админ-панели.
8. По выбору добавляет Wake-on-LAN.
9. Для России предлагает Forkop или Netshift, настраивает DNS и принимает ссылку сервера или подписки.
10. Для Вьетнама предлагает OpenClash и базовые настройки для WARP; конфигурацию WARP нужно добавить вручную. Также можно создать правила маршрутизации Steam через WARP.
11. По выбору устанавливает случайный ASCII MOTD и создаёт шаблон hotplug-обработчика кнопки GL-MT3000. Логику действий для кнопки пользователь задаёт самостоятельно.
12. Печатает сводку адресов и ручных шагов, затем предлагает перезагрузить роутер.

Выбор «другая страна» задаёт UTC и запрашивает двухбуквенный код страны Wi-Fi; для этой ветки страновые компоненты обхода блокировок не запускаются. Неизвестный ответ использует ветку Forkop/Netshift с UTC.

## Важные замечания

- Это мастер первичной установки, а не средство отката. Перед запуском сохраните нужные настройки роутера.
- Изменение LAN-адреса разрывает текущую SSH-сессию. При замене пакета Wi-Fi запускать мастер безопаснее по кабелю.
- Установка AdGuard Home меняет конфигурацию DNS и DHCP.
- Настройка OpenClash удаляет некоторые существующие конфиги, базы и резервные копии OpenClash без резервирования. Рассчитывайте на чистую установку.
- Tailscale получает разрешения firewall, заданные скриптом, включая входящий трафик из tailnet.
- OpenClash требует отдельный YAML-конфиг WARP; пользователь добавляет его вручную.
- Шаблон слайдера создаёт только журналирование событий, без готовых действий при переключении.
